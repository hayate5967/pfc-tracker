# PFCカロリー記録アプリ

食事の写真を撮るだけで、自分が登録した食べ物から自動認識してPFC・カロリーを記録するWebアプリです。

**デモ**: https://pfc-tracker-six.vercel.app

---

## 概要

食事管理アプリの多くは手動での食品検索が必要ですが、このアプリはカメラで撮影するだけで記録できます。

ポイントは「世界中の食品データベースから探す」のではなく、**自分がよく食べる食品だけを事前登録**しておく設計にしたことです。これにより、汎用モデルよりも高精度な認識が実現できます。また、画像分類はブラウザ内のTensorFlow.jsで完結するため、APIコストが一切かかりません。

## 機能

- **写真で食事記録** — カメラで撮影するだけで食べ物を自動認識・記録
- **ブラウザ内ML** — TensorFlow.js + MobileNetによるオンデバイス画像分類。サーバーへの画像送信なし
- **個人最適化された認識精度** — 汎用食品DBではなく、自分が登録した食品の中から分類するため精度が高い
- **PFC・カロリー管理** — 1日の目標設定とダッシュボードでの進捗確認
- **重さ入力の柔軟性** — 固定グラム数またはボタン選択式の2モード

## 技術スタック

| 役割 | 技術 |

| ホスティング | Vercel |

## アーキテクチャのポイント

```
撮影 → MobileNetで特徴抽出 → KNN（コサイン類似度）で登録済み食品と照合 → 認識結果表示
```

- 登録時・記録時ともに画像処理はすべてブラウザ内で完結（TensorFlow.js）
- Supabaseには食品メタデータ・記録ログ・参照用画像のみ保存
- 特徴ベクトルはセッション中にキャッシュし、再分類コストを削減

## 使い方

### 食品の登録

1. **食べ物** タブ → **追加** ボタン
2. 名前・PFC（100gあたり）・カロリーを入力し、重さモードを選択
3. 写真を1枚以上撮影して登録（複数枚・異なる角度で登録すると精度が上がります）

### 食事の記録

1. **記録** タブ → カメラを起動
2. 撮影すると自動で食べ物を認識
3. 重さを選択 → PFC・カロリーが自動計算されて保存

### 目標設定

**目標** タブで1日のカロリー・PFC目標を設定します。ダッシュボードに進捗が表示されます。
